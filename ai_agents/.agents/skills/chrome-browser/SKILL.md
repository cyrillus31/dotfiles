---
name: chrome-browser
description: "Interact with websites in the user’s Chrome browser when a connected browser integration is available."
---

Discover the connected Chrome tools and inspect tabs. Open a task-specific tab unless the user identified an existing tab to use. Read page structure before clicking or typing and verify each resulting page. Respect the user’s requested scope and obtain any required authorization before submissions or account changes. If the integration is unavailable, state that limitation; do not substitute a different authenticated browser silently.
