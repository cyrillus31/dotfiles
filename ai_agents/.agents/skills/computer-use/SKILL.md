---
name: computer-use
description: "Operate a desktop application or inspect the screen when the user requests computer interaction."
---

Discover desktop screenshot and input tools and their access requirements. Inspect the screen before interacting. Prefer application APIs or connected tools when they can perform the requested operation reliably. Make small observable changes and confirm the result with a fresh screenshot. Stop for user input when authentication or a required authorization cannot be completed by the agent. If desktop tools are absent, provide concrete instructions without pretending to have acted.
