---
name: deep-research
description: "Research a question across multiple sources and synthesize a sourced report when broad investigation is requested."
---

Clarify only scope that materially affects the result. Break the question into researchable claims, search primary sources and appropriate independent evidence, and open the relevant pages. Separate established facts, conflicting accounts, and inference; record publication dates for time-sensitive claims. Use parallel agents only when available and authorized. Deliver a coherent report answering the actual question, with links near supported claims and explicit unresolved gaps. Save a separate report only when requested or appropriate to the established workflow.
