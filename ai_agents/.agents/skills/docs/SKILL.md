---
name: docs
description: "Create or edit a collaborative document when the user requests a saved page, proposal, report, or other shared document."
---

Discover available document or page connectors and read their required usage guidance. Identify the requested destination and existing document before writing. Preserve established formatting and unrelated content. Use a connected document tool when available; if none is connected, draft in chat and explain what is needed to save it. Ordinary questions and chat drafts do not authorize creating a document. Verify the saved content and return its link.
