name: docx
description: "Create, read, or edit Word .docx documents, including templates and tracked changes."
---

Inspect the input document and identify the requested output. For reading, use an installed DOCX parser or pandoc; for new files use python-docx or an available document library. For edits, preserve styles, relationships, headers, footers, and existing tracked changes. Use ZIP/XML editing when the library cannot preserve required features. Check dependencies before use. Reopen the output to verify text and structure, and render or preview pages when visual fidelity matters. Return the resulting file.
