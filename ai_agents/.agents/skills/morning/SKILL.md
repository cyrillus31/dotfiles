---
name: morning
description: "Prepare the user’s morning briefing or configure a recurring briefing when explicitly requested."
---

Inspect available calendar, email, chat, and task connectors. Gather today’s events in the user’s timezone, immediate deadlines, and messages requiring action; cite or link each actionable item. Distinguish confirmed commitments from inferred priorities. Produce a concise briefing in the user’s language, with schedule conflicts and the next useful action. If requested, create a standalone HTML brief. Configure recurring execution only when asked and when scheduling tools are available. Report missing source access without inventing events.
