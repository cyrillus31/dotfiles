---
name: pdf
description: "Read, create, merge, split, rotate, annotate, or extract information from PDF files."
---

Inspect page count, text availability, encryption, and the requested page range. Use installed tools such as pypdf for page operations, pdfplumber for tables, and a renderer plus OCR for scanned pages. For creation use a PDF library or export from a suitable document tool. Preserve the original input unless replacement is requested. Reopen the output, verify page count and extracted content, and inspect rendered pages for layout-sensitive changes. Return the output file and identify any OCR uncertainty.
